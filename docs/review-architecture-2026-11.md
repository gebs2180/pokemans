# Architecture and slop review, 2026-11-02

This review covers the whole repo: the backend modules, valuation-core, persistence, the web app, tests, deploy and docs. Seven reviewers worked in parallel, one per area (identity/config, intake/catalog/condition, offers/valuation/pricing, data model, web, tests, deploy). I checked their key claims against the code before including them. It leaves out the 14 findings in [audit-2026-11-02.md](audit-2026-11-02.md), all closed, and the UX review of 2026-11-01. Diagrams of the system as built are in [architecture/](architecture/README.md).

**Count:** 1 high, 31 medium, 26 low across 58 findings (the "fine as is" list isn't numbered). **14 need Zach's decision**, listed at the end.

**File clash:** session `ux-8-11` is editing the offers, market and listing files now. Findings that touch `offers/*` or `web/src/pages/{OfferPanel,MarketPage,SoldPanel}.tsx` (7, 8, 9, 11, 21, 22, 24, 25, 26, 28, 37) should wait until that PR merges.

Columns: **Sev** is severity; **Size** is S (under an hour), M (half a day) or L (a day or more); **Dec** is whether Zach decides first.

## What's good

- **The module boundaries are real.** Spring Modulith `verify()` passes, and the internals are package-private: `offers` and `reporting` export nothing, and four modules export one type each. The dependency graph is a clean DAG ([02-modules.md](architecture/02-modules.md)). Ports are used where they pay for themselves: `CaptureFreeze` keeps intake from depending on offers.
- **The math lives in one place.** valuation-core holds every formula, with a full trace. A grep of `app/` finds no duplicated BigDecimal arithmetic. The worked example is a golden test to the cent, and jqwik properties check that nothing steps up, the caps hold, and grade 1 never anchors. Every CLAUDE.md pricing rule has a named test, except the three listed in finding 12.
- **The database enforces the invariants it can.** `refuse_update()` triggers cover 21 tables. Partial unique indexes enforce "closes once", "one current assessment" and "one label per listing". Undo appends rows, and lost races come back as 409s. Every repository method is used.
- **Security fails closed.** ADMIN comes only from the MFA token. `OrgAccess` returns 404, not 403. Invite tokens are hashed, presigned PUTs are constrained, and `ImageGuard` checks uploads. `RouteSweepTest` reads Spring's own route map, so a new unscoped route fails CI.
- **The lease queues are a good pattern.** They use `SKIP LOCKED`, a lease, an AFTER_COMMIT kick and a poll as the retry path.
- **Config and ops hygiene.** Config is records-based with no `@Value`, `open-in-view: false` and `ddl-auto: validate`. Actions are pinned by SHA, the backend image runs as non-root, and R2 tokens are least-privilege. There is a real restore test, CI requires Docker, and JaCoCo gates valuation-core at 95/90.
- **The web app holds no money math.** Prices, confidence, deadlines (except finding 17) and next steps all come from the API. Accessibility is taken seriously, and comments explain why rather than narrate.
- **Little classic slop.** There are no `@Disabled` tests, no self-mocking, no single-implementation interfaces without a reason, and no unused dependencies.

## Fine as is

- The issuer check is duplicated in `SecurityConfig`.
- `/api/me` returns debug data and has a small N+1.
- `S3BlobStore` uses `toLowerCase()` without a Locale.
- `CatalogProvider` isn't swappable, with TCGDEX hard-coded. YAGNI until there's a second catalog.
- `PreGradeProvider.Local` throws `UnsupportedOperationException`.
- `AuthenticityRisk` is frozen when a catalog card is created.
- Admin web routes are gated only by the backend, which is enforced and tested. The lazy chunks keep admin code off phones.
- The custom date picker works and is tested. Don't extend it.
- `Shipping.java` and `OfferEntities.java` hold several types per file. Split them only when touching 23.
- Money outside comps and snapshots has no currency column. That's fine for USD-only; change hld.md:218 to say so (folded into 15).
- `org_id` is copied onto child rows with no composite FK, so tenancy is enforced in the app only, and tested by `RouteSweepTest`.
